# 构建与安装指南

> Ω Notes V2 桌面应用的构建、打包与安装流程。

---

## 前置要求

| 依赖 | 最低版本 | 说明 |
|---|---|---|
| **Node.js** | 18+ | 推荐 20 LTS |
| **npm** | 9+ | 随 Node.js 附带 |
| **Rust** | 1.77+ | 通过 [rustup.rs](https://rustup.rs) 安装 |
| **Tauri CLI** | 2.x | `npm install` 时自动安装（项目 devDependencies） |

### Windows 额外要求

- **Visual Studio Build Tools 2022**（含 C++ 桌面开发工作负载）
- **WebView2**（Windows 10 1803+ 已预装）

### macOS 额外要求

- **Xcode Command Line Tools**：`xcode-select --install`

### Linux 额外要求

- 参考 [Tauri 官方 Linux 依赖](https://v2.tauri.app/start/prerequisites/#linux)

---

## 开发模式

```bash
# 1. 安装依赖
npm install

# 2. 启动开发模式（前端热更新 + Rust 后端）
npm run tauri:dev
```

首次运行需编译 Rust 依赖，耗时 2–5 分钟。后续增量编译通常 5–15 秒。

如果只需调试前端（不启动 Rust 后端）：

```bash
npm run dev
```

此模式下 Tauri 插件（自启、全局快捷键、文件系统）不可用，数据降级为 localStorage。

## 构建生产版本

```bash
npm run tauri:build
```

此命令会：

1. 运行 `vue-tsc` 类型检查
2. 运行 `vite build` 打包前端
3. 编译 Rust 后端（Release 模式）
4. 生成平台安装包

### 构建产物

构建完成后，安装包位于：

```
src-tauri/target/release/bundle/
├── nsis/
│   └── Omega Notes_2.0.0_x64-setup.exe    ← NSIS 安装包（推荐）
└── msi/
    └── Omega Notes_2.0.0_x64_en-US.msi    ← MSI 安装包
```

| 格式 | 特点 | 推荐场景 |
|---|---|---|
| **NSIS (.exe)** | 向导式安装、支持自定义安装路径、自动创建桌面快捷方式 | 个人使用、分发给他人 |
| **MSI (.msi)** | Windows Installer 标准格式、支持组策略部署 | 企业 / IT 管理场景 |

> macOS 构建会生成 `.dmg` 和 `.app`，Linux 构建会生成 `.deb` 和 `.AppImage`。

## 安装

### Windows

#### 方式一：NSIS 安装包（推荐）

1. 双击 `Omega Notes_2.0.0_x64-setup.exe`
2. 按安装向导选择安装路径（默认 `C:\Users\<用户名>\AppData\Local\Omega Notes`）
3. 完成后桌面会出现 **Ω Notes** 快捷方式

#### 方式二：MSI 安装包

1. 双击 `Omega Notes_2.0.0_x64_en-US.msi`
2. 按向导完成安装

### 卸载

- 通过 **设置 → 应用 → 已安装的应用** 搜索「Omega Notes」卸载
- 或在安装目录运行 `Uninstall Omega Notes.exe`

## 数据目录

应用数据存储在系统 AppData 目录：

| 平台 | 路径 |
|---|---|
| Windows | `%APPDATA%\com.nightmin.omega-notes\notes\` |
| macOS | `~/Library/Application Support/com.nightmin.omega-notes/notes/` |
| Linux | `~/.local/share/com.nightmin.omega-notes/notes/` |

> 卸载应用 **不会** 删除笔记数据。如需完全清除，手动删除上述目录。

## 常见问题

### Q: 构建时报 `error: linker 'link.exe' not found`

安装 Visual Studio Build Tools 2022，勾选「使用 C++ 的桌面开发」工作负载。

### Q: 构建时 Rust 编译特别慢

首次编译需下载并编译所有 crate 依赖（约 200+），属正常现象。后续构建为增量编译，速度会快很多。可尝试：

```bash
# 使用 Release 构建缓存
set CARGO_INCREMENTAL=1
npm run tauri:build
```

### Q: 运行时提示 WebView2 缺失

访问 [WebView2 下载页](https://developer.microsoft.com/en-us/microsoft-edge/webview2/) 安装 Evergreen Runtime。

### Q: 开机自启开关在设置中不显示

该功能仅在 Tauri 桌面环境下可用。浏览器模式（`npm run dev`）不显示此选项。
