# Ω Notes V2 — 数据存储机制详解

> 回答一个最重要的问题：我的笔记到底存在哪里？改代码会不会丢数据？

---

## 核心概念：代码和数据是分开的

```
┌──────────────────────────────────────────────────────┐
│                    你的电脑                            │
│                                                      │
│  ┌─────────────────┐      ┌─────────────────┐        │
│  │  代码（菜谱）     │      │  数据（做好的菜） │        │
│  │                 │      │                 │        │
│  │ E:\Code\        │      │ C:\Users\Night\ │        │
│  │ omega-v2\       │      │ AppData\        │        │
│  │ ├── src\        │      │ └── notes\      │        │
│  │ ├── src-tauri\  │      │     ├── a.md    │        │
│  │ └── ...         │      │     ├── b.md    │        │
│  │                 │      │     └── ...     │        │
│  │  改这里 ✅       │      │  笔记在这里 📝  │        │
│  │  不影响数据      │      │  不受代码影响    │        │
│  └─────────────────┘      └─────────────────┘        │
│                                                      │
│  两者完全独立，互不干扰                                 │
└──────────────────────────────────────────────────────┘
```

## 两种运行环境，两种存储方式

`storage.ts` 这个文件会自动判断你在哪个环境运行：

### 环境 1：作为桌面软件运行（Tauri）

```
通过 npm run tauri dev 或安装的 .exe 打开

笔记存储位置：
  Windows: C:\Users\你的用户名\AppData\Roaming\com.omega.notes\notes\
  macOS:   ~/Library/Application Support/com.omega.notes/notes/
  Linux:   ~/.config/com.omega.notes/notes/

每条笔记 = 一个 .md 文件，长这样：

  ┌─── abc123.md ───────────────────────┐
  │ ---                                 │  ← 这部分叫 YAML frontmatter
  │ id: abc123                          │    存储笔记的元信息
  │ title: 我的第一条笔记                │
  │ category: 学习                      │
  │ tags: [Vue, TypeScript]             │
  │ pinned: false                       │
  │ createdAt: 2026-03-18T12:00:00Z     │
  │ updatedAt: 2026-03-18T12:30:00Z     │
  │ ---                                 │
  │                                     │
  │ 这里是笔记的正文内容...              │  ← 标准 Markdown
  │ 用任何编辑器都能打开。                │
  └─────────────────────────────────────┘
```

### 环境 2：在浏览器中运行（开发调试）

```
通过 npm run dev 打开，在浏览器里看

笔记存储位置：
  浏览器的 localStorage（一个浏览器内置的小数据库）
  键名：omega-notes
  格式：JSON 数组

注意：这个只是开发时的降级方案
  - 清浏览器缓存会丢
  - 容量只有 5~10MB
  - 正式使用应该用 Tauri 桌面版
```

## 自动迁移机制

如果你之前一直在浏览器里用（`npm run dev`），积累了一些笔记。
当你第一次用桌面版打开时，系统会自动：

```
1. 检测到 localStorage 里有旧笔记
2. 把它们全部转换成 .md 文件
3. 存到 AppData/notes/ 目录
4. 删除 localStorage 里的旧数据
5. 以后都从文件读取
```

你不需要做任何操作，完全自动。

---

## 什么操作会/不会丢数据？

| 操作 | 数据安全？ | 说明 |
|------|-----------|------|
| 修改代码后重新编译 | ✅ 安全 | 代码和数据在不同文件夹 |
| `npm run tauri build` | ✅ 安全 | 只是编译代码，不碰数据 |
| 删掉 `E:\Code\omega-v2` 整个项目 | ✅ 安全 | 数据在 AppData 里 |
| 卸载 Omega Notes | ✅ 一般安全 | AppData 通常不会被清 |
| 清除浏览器缓存 | ⚠️ 浏览器里的会丢 | 桌面版不受影响 |
| 手动去 AppData 删 notes 文件夹 | ❌ 会丢 | 你主动删了数据 |
| 重装系统（格式化 C 盘） | ❌ 会丢 | 建议提前备份 notes 文件夹 |

## 备份建议

最简单的备份方式：

```
把这个文件夹复制到 U 盘或网盘：
  C:\Users\你的用户名\AppData\Roaming\com.omega.notes\notes\

里面都是 .md 文件，就是普通的文本文件，随便拷。
```
