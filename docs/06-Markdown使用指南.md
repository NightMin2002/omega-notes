# Markdown 高级用法与技巧指南

本文档将帮助你在 Ω Notes V2 中更高效地使用各种实用的 Markdown 和 HTML 特性扩展，实现文档结构的优化和增强排版。

## 1. 内容收缩与展开（可折叠面板）

当你遇到大段的解释代码、过长的报错日志，或是想要先隐藏答案做个自我测验时，使用原生的 HTML `<details>` 标签是个绝佳选择。

### 语法示例

```html
<details>
  <summary>🔍 点击展开查看详情 / 答案</summary>
  
  这里面可以放任意内容！
  
  **支持加粗**、*支持斜体*
  
  - 甚至
  - 无序列表
</details>
```

**渲染效果：**
<details>
  <summary>🔍 点击展开查看详情 / 答案</summary>
  这里面可以放任意内容！
  
  **支持加粗**、*支持斜体*
  - 甚至
  - 无序列表
</details>

## 2. 待办清单（打勾复选框）

列表结合复选框功能，可以帮你将长篇笔记转变为一步步跟进的“执行清单”。

### 语法示例

通过 `- [ ]` (未完成) 和 `- [x]` (已完成) 以及 `[X]` (大小写均可)：

```markdown
### 🚀 产品发布前检查清单：

- [x] 完成用户体验测试并记录问题
- [x] 更新所有遗漏的设计文档
- [ ] 撰写版本迁移指南（进行中）
- [ ] 清理无用资源文件
```

**渲染效果：**
- [x] 完成用户体验测试并记录问题
- [x] 更新所有遗漏的设计文档
- [ ] 撰写版本迁移指南（进行中）
- [ ] 清理无用资源文件

## 3. 表格 (Table) 的排版

如果你需要展示对比数据或是规则文档，标准的 Markdown 表格是最直观的。

### 语法示例

```markdown
| 功能模块 | v1.0 状态 | v2.0 状态 |
| :--- | :---: | ---: |
| 笔记存储 | IndexedDB | 本地 .md 文件 |
| 框架 | 原生 JS | Vue3 + Tauri |
| UI/UX | 基础 | 现代化玻璃拟物 |
```
*(提示：`---`周围的冒号 `:` 代表了这列是对齐左、居中、还是靠右。)*

## 4. 双向链接引用

想要这篇笔记关联到上一篇笔记吗？使用双向链接！

### 语法示例

```markdown
在今天的学习中，我发现它与 [[Vue3 响应式原理]] 这个知识点紧密相关。
```

当您这样写并处于“阅读模式”时，这段文本上的 `Vue3 响应式原理` 会变成一个可以点击的高亮链接。点击后可直接跳转，并且在目标笔记的最底下会自动生成“**反向链接**”提示框，指出是哪里引用了它。

## 5. 高亮与代码段

你可以在两端使用三个反引号 ``` 来表示代码块，若标明语言还能触发彩色的语法高亮：

````markdown
```typescript
interface Note {
  id: string;
  title: string;
  isFavorite: boolean;
}
```
````

## 🎈 总结 
合理的运用收缩板块、清单、双向链接可以让你的知识体系不再是一堆干巴巴的文本，而是变成一个互相关联的结构树。赶紧在笔记里实践试试吧！
