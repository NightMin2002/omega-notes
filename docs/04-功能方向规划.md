## ✅ 阶段一：让"写"变得更爽（已完成）

> 目标：打开软件就想写东西

### 1. ✅ 快速笔记（Quick Note）
Ctrl+Q 弹窗 → 直接打字 → Ctrl+Enter 保存到收件箱。侧边栏显示未整理数量。

### 2. ✅ 实时搜索增强
Ctrl+K 弹出全局搜索：全文搜索标题+内容+标签+分类，搜索结果高亮，键盘上下导航+回车跳转。

### 3. ✅ 笔记模板
新建笔记时显示 6 种模板卡片：空白、会议记录、读书笔记、日记、学习笔记、待办清单。选择后自动填入日期和框架。

### 4. ✅ 图片支持
- **截图粘贴**：分屏 textarea 中 Ctrl+V 直接插入（转 base64）
- **文件选择器**：编辑模式和分屏模式都有「插入图片」按钮
- **Milkdown 编辑器**：支持浏览器复制的图片直接粘贴

---

## ✅ 阶段二：让"找"变得更快（已完成）

> 目标：写了 500 条笔记也不慌

### 5. ✅ 标签系统升级
- 知识库页显示标签云，按使用频率排序
- 点击标签 → 筛选所有带该标签的笔记（`?tag=` URL 参数）
- 一条笔记可以同时属于多个标签

### 6. ✅ 文件夹 + 无限嵌套
分类名用 `/` 分隔即可嵌套：`工作/项目A/文档`。
- 侧边栏「文件夹」区域显示可展开/折叠的树形导航
- 知识库页顶部面包屑：`全部 / 工作 / 项目A`
- 子分类自动包含在父分类筛选结果中

### 7. ✅ 双向链接
- 在笔记内容中使用 `[[笔记标题]]` 引用其他笔记
- 阅读模式自动渲染为可点击的蓝色链接
- 被引用的笔记底部显示「反向链接」面板
- 工具栏「插入链接」按钮：搜索并快速插入
- 兼容 Milkdown WYSIWYG 转义括号

### 8. ✅ 收藏 + 最近打开
- 收藏夹：笔记详情页一键收藏（金色星标），侧边栏入口
- 最近打开：自动记录打开顺序（最多 20 条），侧边栏入口
- 数据导入/导出：侧边栏一键操作，Tauri 环境使用原生保存/打开对话框

## 🔴 阶段三：让它变成"第二大脑"

> 目标：不只是记笔记，而是管理知识

### 9. 日历视图
按日期看笔记：我某天写了什么？这周写了多少？
配合写作统计：今天写了 800 字，本周 3000 字。
> 💡 用 CSS Grid 画月历 + GitHub 风格热力图，纯前端实现，无需新增数据字段。

### 10. 看板模式
把笔记当卡片拖来拖去：
```
  待处理        进行中        已完成
┌────────┐  ┌────────┐  ┌────────┐
│ 买菜单  │  │ 学 Vue │  │ 装系统 │
│ 周日计划│  │        │  │        │
└────────┘  └────────┘  └────────┘
```
> 💡 需要新增 `status` 字段，拖拽可用 HTML5 Drag API。

### 11. 表格/数据库视图
像 Notion 的 Database：同一批笔记，可以用表格、列表、画廊多种方式查看。
> 💡 工程量大，需要自定义 schema，ROI 较低。

### 12. AI 功能
- **智能摘要**：长笔记自动生成摘要
- **智能标签**：根据内容自动建议标签/分类
- **问答**：对着自己的笔记库提问"我之前关于 XX 写了什么？"
- **写作辅助**：帮你续写、改写、翻译
> 💡 接 OpenAI / 本地 Ollama API。可以先从「智能标签推荐」切入。

### 13. 数据同步
电脑 ↔ 手机笔记同步（通过局域网 / 网盘 / 自建服务器）
> 💡 最复杂，需要后端基础设施。

### 14. 多格式导出
- 导出为 PDF / Word / HTML
- 从 Obsidian / Notion 导入
> 💡 PDF 用 `html2pdf.js`，Word 用 `docx` 库。JSON 导入导出已完成。
