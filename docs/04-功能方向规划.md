# 功能方向规划与技术债重构 (TODO)

经过近期的项目全面检阅与中二病词汇清理，我们确定了部分深水区代码的技术债，并规划了未来的功能优化方向。

## 1. 结构重构计划 (Refactoring)
虽然项目的模块化已相当成熟，但仍有以下高优重构点：

- **巨型组件组件化 (`AppSidebar.vue`)**
  当前侧边栏代码膨胀明显，其中包含了极度复杂的文件夹嵌套树逻辑。需要将其内部的 `FolderTree` (文件树递归逻辑) 与 `ShortcutPanel` (底部快捷栏) 等业务剥离为独立的子组件，以降低维护心智负担。

- **桌面悬浮微件页面下沉隔离 (`views/popout/`)**
  悬挂窗面板中实际只对应了两个物理弹窗，但内部硬挂载了众多零碎子内容模块（如 `HubTasks.vue`, `HubTimer.vue`, `HubLife.vue`, `HubSettings.vue`, `HubExpandedBody.vue`）。这些模块并不直接绑定路由，理应将其下沉重构至 `src/components/popout/`，保证 `views/` 目录的“纯洁性”（仅存放有正式路由的顶层视图）。

## 2. 交互体验打磨 (UX/UI Polish)
- **设置页数据交互体验**：强化用户对数据导出、存储位置迁移操作的防呆提示进度及平滑化。
- **拖放与右键能力延展**：现有的侧边栏可尝试扩展拖拽合并笔记分类的逻辑。
