# Ω Notes V2 — 功能方向规划

> 从「能用」到「好用」到「离不开」，分阶段推进。

---

## 已完成回顾

### Phase 1 ✅ 骨架搭建
Vue 3 + Vite + TypeScript 项目初始化、Design Token 体系（暗色/亮色双主题）、全局样式重置、Header + Sidebar 布局、路由配置、笔记 Store（CRUD + 分类 + 搜索 + 排序）、主题 Store、页面过渡动画。

### Phase 2 ✅ 编辑器升级
Milkdown v7 所见即所得编辑器、markdown-it 阅读渲染、highlight.js 代码高亮、KaTeX 数学公式（编辑 + 阅读双端渲染）。

### Phase 3 ✅ 桌面化
Tauri 2 集成、本地 .md 文件存储（YAML frontmatter 元数据）、浏览器 localStorage 自动降级、旧数据迁移、全局快捷键（Ctrl+Shift+N/O）、系统托盘常驻。

### Phase 4 ✅ 功能增强
快速笔记（Ctrl+Q）、全局搜索（Ctrl+K）、收件箱系统、笔记模板（6 种预设）、图片支持（截图粘贴 + 文件选择器，base64 嵌入）、智能粘贴、分屏编辑、Markdown 增强（表格斑马纹/任务列表/删除线）、快捷键面板。

### Phase 5 ✅ 组织与发现
收藏夹 + 最近打开、标签云 + 点击筛选、文件夹无限嵌套（`/` 分隔路径 + 树形导航 + 面包屑）、双向链接（`[[title]]` 语法 + 反向链接面板）、数据导入/导出（JSON + .md）。

---

### Phase 6 ✅ 体验打磨 & 工程治理
设置面板（外观/编辑器/数据/关于 四分区）、笔记回收站（软删除 + 恢复 + 永久删除 + 自动清理）、拖拽排序（笔记卡片排序 + 拖入文件夹改分类）、Markdown 工具栏增强（14 按钮）、版本号统一 + CHANGELOG、`src/types/` 集中类型定义、搜索防抖优化。

**v2.1.0 架构重构**（2026-03-28）：
- 组件拆分：提取 `WikiLinkPicker` / `SplitEditor` / `BacklinksPanel` 共享组件，消灭 WriteView ↔ NoteDetailView 模板/样式重复
- 工具层整合：`dataio.ts` 复用 `storage.ts` 的 `parseFrontmatter` / `parseTags`
- 状态治理：`settings.ts` 消除双重状态源（`computed` 单一数据源）
- 性能优化：`notes.ts` 新增 `noteMap` computed Map 索引（9 处 O(n) → O(1)）
- 模板修复：`templates.ts` 改为工厂函数 `getTemplates()` 动态生成日期
- 路由修复：`AppSidebar` `navigateFolder` 从 `window.location.hash` 改用 `router.push()`
- AppHeader hamburger 图标去重 + 添加 ☰ ↔ × 切换动画
- NoteDetailView **877** 行 → **~470** 行（-47%），WriteView **785** 行 → **~530** 行（-32%）

## 🔴 Phase 7：知识管理层

> 目标：从「记笔记」到「管理知识」

### 7.1 日历视图 + 写作统计
按日期浏览笔记：我某天写了什么？这周写了多少？

- CSS Grid 月历 + GitHub 风格热力图
- 字数统计（今日/本周/本月/总计）
- 纯前端实现，无需新增数据字段

### 7.2 知识图谱
基于双向链接的可视化网络图，发现笔记间的隐藏关联。

- 可用 D3.js / vis-network / Cytoscape.js
- 节点大小 = 链接数量，颜色 = 分类
- 点击节点跳转到笔记

### 7.3 多格式导出
- PDF 导出（`html2pdf.js`）
- Word 导出（`docx` 库）
- HTML 静态页导出（含样式）

### 7.4 Obsidian 导入
解析 Obsidian vault 的 `.md` 文件 + `[[wikilink]]` + YAML frontmatter，批量导入。

### 7.5 笔记版本历史
每次保存时记录差异快照，支持回溯到任意版本。

## 🟣 Phase 8：智能化

> 目标：让笔记库成为「第二大脑」

### 8.1 AI 智能标签
根据笔记内容自动建议标签和分类。接 OpenAI API / 本地 Ollama。

### 8.2 AI 摘要
长笔记一键生成摘要，显示在笔记卡片预览中。

### 8.3 AI 问答
对整个笔记库提问：「我之前关于 XX 写了什么？」基于 Embedding 的语义搜索。

### 8.4 AI 写作辅助
续写、改写、翻译、润色。编辑器内联触发。
