# Ω Notes V2 — 功能方向规划

> 从"能用"到"好用"到"离不开"，分三个阶段。

---

## 🟢 目前已有的

- 笔记增删改查
- Markdown 编辑（Milkdown 所见即所得）
- 数学公式（KaTeX）
- 代码高亮
- 分类 + 搜索
- 置顶笔记
- 暗色/亮色主题
- 本地 .md 文件持久化
- 全局快捷键
- 系统托盘

---

## 🔵 阶段一：让"写"变得更爽

> 目标：打开软件就想写东西

### 1. 快速笔记（Quick Note）
打开应用 → 直接开始打字 → 自动保存到"收件箱"分类。
不需要填标题、选分类。想到什么先记下来，之后再整理。
> 很多灵感都是一闪而过的，如果要先填标题再写内容，灵感就跑了。

### 2. 实时搜索增强
现在只能搜标题。可以做到：
- **全文搜索**：搜内容里的关键词
- **搜索结果高亮**：匹配的文字变色
- **快捷键搜索**：Ctrl+K 弹出搜索框（像 VS Code 那样）

### 3. 笔记模板
写笔记时可以选模板：
- "会议记录" → 自动填入日期、参与者、议题、结论的框架
- "读书笔记" → 书名、作者、要点、感想
- "日记" → 日期、心情、今天发生了什么
- 自定义模板

### 4. 图片支持
在笔记里粘贴图片 → 自动保存到本地 → 显示在编辑器中。
（现在只能写文字，不能插图）

---

## 🟡 阶段二：让"找"变得更快

> 目标：写了 500 条笔记也不慌

### 5. 标签系统升级
现在标签只是文字。可以升级为：
- 点击标签 → 看到所有同标签笔记
- 标签云：哪个标签用得多一目了然
- 一条笔记可以同时属于多个分类

### 6. 文件夹 + 无限嵌套
```
我的笔记/
├── 工作/
│   ├── 项目A/
│   │   ├── 需求文档.md
│   │   └── 会议记录.md
│   └── 项目B/
├── 学习/
│   ├── Vue/
│   ├── Rust/
│   └── 数学/
└── 日常/
```
像电脑文件夹一样，想建几层建几层。

### 7. 双向链接
在笔记 A 里提到笔记 B → 自动建立关联。
打开笔记 B → 能看到"哪些笔记提到了我"。
> 这是 Obsidian / Roam Research 的核心功能，很多人因为这个功能选择它们。

### 8. 收藏 + 最近打开
- 收藏夹：常用的笔记一键收藏
- 最近打开：像浏览器历史记录一样

---

## 🔴 阶段三：让它变成"第二大脑"

> 目标：不只是记笔记，而是管理知识

### 9. 日历视图
按日期看笔记：我某天写了什么？这周写了多少？
配合写作统计：今天写了 800 字，本周 3000 字。

### 10. 看板模式
把笔记当卡片拖来拖去：
```
  待处理        进行中        已完成
┌────────┐  ┌────────┐  ┌────────┐
│ 买菜单  │  │ 学 Vue │  │ 装系统 │
│ 周日计划│  │        │  │        │
└────────┘  └────────┘  └────────┘
```
学习计划、项目管理都能用。

### 11. 表格/数据库视图
像 Notion 的 Database：同一批笔记，可以用表格、列表、画廊多种方式查看。

### 12. AI 功能
- **智能摘要**：长笔记自动生成摘要
- **智能标签**：根据内容自动建议标签/分类
- **问答**：对着自己的笔记库提问"我之前关于 XX 写了什么？"
- **写作辅助**：帮你续写、改写、翻译

### 13. 数据同步
电脑 ↔ 手机笔记同步（通过局域网 / 网盘 / 自建服务器）

### 14. 导入 / 导出
- 导入：从 Obsidian / Notion / 有道云笔记一键导入
- 导出：导出为 PDF / Word / HTML

---

## 我推荐的优先级排序

如果按"投入产出比"排序（花最少力气，获得最大的使用体验提升）：

| 优先级 | 功能 | 难度 | 理由 |
|--------|------|------|------|
| ⭐⭐⭐ | 快速笔记 | ⭐ | 极简，但极大降低"开始写"的门槛 |
| ⭐⭐⭐ | 全文搜索 + Ctrl+K | ⭐⭐ | 笔记多了以后必须有 |
| ⭐⭐⭐ | 图片支持 | ⭐⭐ | 不能插图的笔记软件是残废的 |
| ⭐⭐ | 文件夹嵌套 | ⭐⭐ | 分类不够用时的刚需 |
| ⭐⭐ | 笔记模板 | ⭐ | 简单但实用 |
| ⭐⭐ | 收藏 + 最近打开 | ⭐ | 小功能大便利 |
| ⭐ | 双向链接 | ⭐⭐⭐ | 强大但需要笔记量积累后才有感 |
| ⭐ | 日历/看板 | ⭐⭐⭐ | 锦上添花 |
| ⭐ | AI 功能 | ⭐⭐⭐⭐ | 有趣但需要 API 接入 |
