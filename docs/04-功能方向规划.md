> 从"能用"到"好用"到"离不开"，分三个阶段。

---

- Markdown 编辑（Milkdown 所见即所得 + 分屏源码模式）

- 代码高亮
- 分类 + 搜索
- 置顶笔记
- 暗色/亮色主题
- 本地 .md 文件持久化

- 全文搜索（标题+内容+标签+分类，高亮匹配，键盘导航）

## ✅ 阶段一：让"写"变得更爽（已完成）

> 目标：打开软件就想写东西

### 1. ✅ 快速笔记（Quick Note）
Ctrl+Q 弹窗 → 直接打字 → Ctrl+Enter 保存到收件箱。侧边栏显示未整理数量。

### 2. ✅ 实时搜索增强
Ctrl+K 弹出全局搜索：全文搜索标题+内容+标签+分类，搜索结果高亮，键盘上下导航+回车跳转。

### 3. ✅ 笔记模板
新建笔记时显示 6 种模板卡片：空白、会议记录、读书笔记、日记、学习笔记、待办清单。选择后自动填入日期和框架。

### 4. ✅ 图片支持
- **截图粘贴**：分屏 textarea 中 Ctrl+V 直接插入（转 base64）
- **文件选择器**：编辑模式和分屏模式都有「插入图片」按钮
- **Milkdown 编辑器**：支持浏览器复制的图片直接粘贴

---

## 🟡 阶段二：让"找"变得更快

> 目标：写了 500 条笔记也不慌

### 5. 标签系统升级
现在标签只是文字。可以升级为：
- 点击标签 → 看到所有同标签笔记
- 标签云：哪个标签用得多一目了然
- 一条笔记可以同时属于多个分类

### 6. 文件夹 + 无限嵌套
```
我的笔记/
├── 工作/
│   ├── 项目A/
│   │   ├── 需求文档.md
│   │   └── 会议记录.md
│   └── 项目B/
├── 学习/
│   ├── Vue/
│   ├── Rust/
│   └── 数学/
└── 日常/
```
像电脑文件夹一样，想建几层建几层。

### 7. 双向链接
在笔记 A 里提到笔记 B → 自动建立关联。
打开笔记 B → 能看到"哪些笔记提到了我"。
> 这是 Obsidian / Roam Research 的核心功能，很多人因为这个功能选择它们。

### 8. 收藏 + 最近打开
- 收藏夹：常用的笔记一键收藏
- 最近打开：像浏览器历史记录一样

---

## 🔴 阶段三：让它变成"第二大脑"

> 目标：不只是记笔记，而是管理知识

### 9. 日历视图
按日期看笔记：我某天写了什么？这周写了多少？
配合写作统计：今天写了 800 字，本周 3000 字。

### 10. 看板模式
把笔记当卡片拖来拖去：
```
  待处理        进行中        已完成
┌────────┐  ┌────────┐  ┌────────┐
│ 买菜单  │  │ 学 Vue │  │ 装系统 │
│ 周日计划│  │        │  │        │
└────────┘  └────────┘  └────────┘
```
学习计划、项目管理都能用。

### 11. 表格/数据库视图
像 Notion 的 Database：同一批笔记，可以用表格、列表、画廊多种方式查看。

### 12. AI 功能
- **智能摘要**：长笔记自动生成摘要
- **智能标签**：根据内容自动建议标签/分类
- **问答**：对着自己的笔记库提问"我之前关于 XX 写了什么？"
- **写作辅助**：帮你续写、改写、翻译

### 13. 数据同步
电脑 ↔ 手机笔记同步（通过局域网 / 网盘 / 自建服务器）

### 14. 导入 / 导出
- 导入：从 Obsidian / Notion / 有道云笔记一键导入
- 导出：导出为 PDF / Word / HTML
