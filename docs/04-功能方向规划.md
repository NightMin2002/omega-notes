# Ω Notes V2 — 功能方向规划

> 从「能用」到「好用」到「离不开」，分阶段推进。

---

## 已完成回顾

### Phase 1 ✅ 骨架搭建
Vue 3 + Vite + TypeScript 项目初始化、Design Token 体系（暗色/亮色双主题）、全局样式重置、Header + Sidebar 布局、路由配置、笔记 Store（CRUD + 分类 + 搜索 + 排序）、主题 Store、页面过渡动画。

### Phase 2 ✅ 编辑器升级
Milkdown v7 所见即所得编辑器、markdown-it 阅读渲染、highlight.js 代码高亮、KaTeX 数学公式（编辑 + 阅读双端渲染）。

### Phase 3 ✅ 桌面化
Tauri 2 集成、本地 .md 文件存储（YAML frontmatter 元数据）、浏览器 localStorage 自动降级、旧数据迁移、全局快捷键（Ctrl+Shift+N/O）、系统托盘常驻。

### Phase 4 ✅ 功能增强
快速笔记（Ctrl+Q）、全局搜索（Ctrl+K）、收件箱系统、笔记模板（6 种预设）、图片支持（截图粘贴 + 文件选择器，base64 嵌入）、智能粘贴、分屏编辑、Markdown 增强（表格斑马纹/任务列表/删除线）、快捷键面板。

### Phase 5 ✅ 组织与发现
收藏夹 + 最近打开、标签云 + 点击筛选、文件夹无限嵌套（`/` 分隔路径 + 树形导航 + 面包屑）、双向链接（`[[title]]` 语法 + 反向链接面板）、数据导入/导出（JSON + .md）。

---

## 🟠 Phase 6：体验打磨 & 工程治理

> 目标：从「能用」到「让人想用」，同时偿还技术债

### 6.1 设置面板
集中管理应用偏好：字体选择、编辑器偏好（默认模式/自动保存间隔）、快捷键自定义、存储路径、导出偏好。目前这些配置散落在各处或根本不可配置。

- 新增路由 `/settings` 或侧边栏抽屉
- 新增 `src/stores/settings.ts` 统一管理偏好项
- 持久化到 localStorage / Tauri AppData

### 6.2 笔记回收站
软删除机制，防止误删造成数据丢失。

- 删除笔记时移至回收站而非直接物理删除
- 回收站列表页（侧边栏入口）
- 支持恢复 / 永久删除
- 可选：30 天自动清理

### 6.3 拖拽排序
提升笔记列表和文件夹的交互体验。

- 笔记卡片拖拽排序（持久化自定义顺序）
- 文件夹拖拽排序 / 笔记拖入文件夹改变分类
- 使用 HTML5 Drag and Drop API 或轻量库

### 6.4 Markdown 工具栏增强
WYSIWYG 模式下添加常用格式的快捷按钮。

- 插入表格、分割线、引用块、代码块
- 标题级别快速切换
- 格式刷 / 清除格式

### 6.5 组件拆分（工程治理）
3 个大文件已到维护临界点：

| 文件 | 当前大小 | 拆分方案 |
|---|---|---|
| `NoteDetailView.vue` | 26KB | → 阅读面板 / 编辑面板 / 反向链接面板 / 元信息栏 |
| `WriteView.vue` | 24KB | → 模板选择器 / 编辑区 / 元信息表单 |
| `AppSidebar.vue` | 19KB | → 文件夹树 / 快捷键面板 / 导航列表 |

### 6.6 性能优化
笔记数量增长后的体验保障。

- 虚拟列表（500+ 笔记列表滚动）
- 图片懒加载
- 搜索防抖优化

### 6.7 版本号 & CHANGELOG
- 统一 `package.json` 与 `tauri.conf.json` 版本号
- 创建 CHANGELOG.md

### 6.8 类型目录
创建 `src/types/`，提取 `Note`, `Template`, `NoteFilter` 等共享类型定义。

## 🔴 Phase 7：知识管理层

> 目标：从「记笔记」到「管理知识」

### 7.1 日历视图 + 写作统计
按日期浏览笔记：我某天写了什么？这周写了多少？

- CSS Grid 月历 + GitHub 风格热力图
- 字数统计（今日/本周/本月/总计）
- 纯前端实现，无需新增数据字段

### 7.2 知识图谱
基于双向链接的可视化网络图，发现笔记间的隐藏关联。

- 可用 D3.js / vis-network / Cytoscape.js
- 节点大小 = 链接数量，颜色 = 分类
- 点击节点跳转到笔记

### 7.3 多格式导出
- PDF 导出（`html2pdf.js`）
- Word 导出（`docx` 库）
- HTML 静态页导出（含样式）

### 7.4 Obsidian 导入
解析 Obsidian vault 的 `.md` 文件 + `[[wikilink]]` + YAML frontmatter，批量导入。

### 7.5 笔记版本历史
每次保存时记录差异快照，支持回溯到任意版本。

---

## 🟣 Phase 8：智能化

> 目标：让笔记库成为「第二大脑」

### 8.1 AI 智能标签
根据笔记内容自动建议标签和分类。接 OpenAI API / 本地 Ollama。

### 8.2 AI 摘要
长笔记一键生成摘要，显示在笔记卡片预览中。

### 8.3 AI 问答
对整个笔记库提问：「我之前关于 XX 写了什么？」基于 Embedding 的语义搜索。

### 8.4 AI 写作辅助
续写、改写、翻译、润色。编辑器内联触发。
